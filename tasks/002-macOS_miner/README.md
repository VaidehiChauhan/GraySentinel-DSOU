# Day 2: macOS Malware Analysis & Cryptomining Investigation

## 1. Objective
To understand and investigate a simulated macOS attack chain involving phishing, vulnerability exploitation, Command and Control (C2), persistence, cryptocurrency mining, and remediation.

## 2. Lab Activities

- **Phase 1 – Phishing Email Analysis:** Analysed a suspicious Office document using Oletools to identify malicious VBA macros and suspicious indicators.
- **Phase 2 – Vulnerability Exploitation:** Studied a simulated macOS Screen Sharing authentication-bypass vulnerability.
- **Phase 3 – C2 & Post-Exploitation:** Explored C2 deployment and SSH-based persistence.
- **Phase 4 – Monero Miner Deployment:** Investigated XMRig cryptocurrency miner deployment and persistence mechanisms.
- **Phase 5 – OSINT Investigation:** Used Cookie-OSINT and DNS queries to gather publicly available information.
- **Phase 6 – Detection & Remediation:** Explored process termination, removal of suspicious files, and Wazuh detection-rule preparation.

## 3. Tools Used
- Kali Linux
- Oletools
- Python 3
- Metasploit
- GEF

- Wazuh

## 4. Deliverables
- CISO Executive Report

- Synthetic Detection PoC
- Lab Activity Documentation

## 5. Key Learnings
- Analysing suspicious Office documents and VBA macros.
- Understanding authentication-bypass attacks.
- Learning how attackers establish persistence and C2 communication.
- Understanding cryptocurrency mining malware.
- Performing basic OSINT investigation.
- Understanding detection, containment, and eradication concepts.

## 6. Learning Outcome
Gained practical exposure to a simulated macOS attack chain and the investigation steps involved in identifying suspicious activity and understanding defensive remediation techniques.

**Note:** This repository documents a controlled lab exercise. Command output and simulated results should be validated before treating them as proof of successful exploitation or remediation.
